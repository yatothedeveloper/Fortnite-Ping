Fortnite-Ping Tracker
Live Demo: https://yatothedeveloper.github.io/Fortnite-Ping/

The Backstory
Look, I’m a gamer. And like most gamers, I got tired of opening heavy, ad-filled websites just to check my ping before jumping into a lobby. I wanted something instant, minimal, and built for me. So, I decided to stop complaining and build my own solution.

What I Learned (The Hard Way)
This wasn't a "copy-paste" job. To make this work, I had to dive deep into how APIs actually talk to each other. I spent a lot of nights staring at code, dealing with JSON structures, and figuring out why my requests were failing. I didn't have all the answers—I spent hours digging through documentation and trial-and-error debugging. It was frustrating at times, but actually making that number appear on the screen in real-time? That was worth every minute of the headache.

The Challenge
The biggest hurdle was the latency data itself. Making the UI responsive and ensuring the data was accurate meant I had to optimize the way the app fetches information. It forced me to move beyond basic HTML and CSS and really understand how JavaScript handles asynchronous tasks.

Teamwork
I want to be clear: I didn’t build this in a bubble. I’ve had some great friends and fellow developers who jumped in to help me fix bugs and give feedback on the layout. Learning how to take advice, implement suggestions, and collaborate was honestly just as important as the code itself.

Why This Matters to Me
At the end of the day, this project is proof that I can take an idea, struggle through the technical mess, and actually ship something that works. It’s a tool I use every time I play, and it’s a constant reminder that with enough persistence, I can figure out anything.
